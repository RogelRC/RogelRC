### Featured Projects

**[MHP3 Custom Sets](https://mhp3csc.vercel.app/)**  
Advanced armor set calculator for _Monster Hunter Portable 3rd_.  
Built with **SvelteKit + TypeScript + Tailwind + Redis**.  
Includes save file import, complex search engine, material calculation and live analytics.

→ [Live Demo](https://mhp3csc.vercel.app/) · [Source Code](https://github.com/RogelRC/mhp3csc)

**[Black Hole Simulator](https://github.com/RogelRC/black-hole-sim)**  
Real-time OpenGL raytracer that simulates a Schwarzschild black hole using compute shaders.  
Includes gravitational lensing, accretion disk with Doppler beaming and photon ring.
